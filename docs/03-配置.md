# 03 · 配置

> **目标**：让她真的会说话、记得住人、不会乱发消息。
> **做完的判据**：本篇 §7 的「最小可用配置」能跑通，§8 的自检全过。

配置分三块，**按这个顺序配**：

```
① qqbot 通道配置（能连上 QQ）
      ↓
② 人格 + 记忆配置（她是谁、记得什么）
      ↓
③ 玩法扩展配置（积分/商店/点歌要不要开）
```

---

## 1. 配置写在哪

**所有配置都写在一个 YAML 文件里**：

```
{PROFILE_DIR}/cordis.patch.yml
```

它长这样（省略号是别的内容）：

```yaml
- insert:
    - id: im-qqbot-2                 # 通道实例名，随便起
      name: '@zaofan/dsh-qqbot'
      config:
        appId: '你的appId'
        appSecret: '你的appSecret'
        # ... 下面全是配置项

    - id: bnnbotbox
      name: 'dsh-bnnbotbox'
      config:
        enabled: true
        # ... 人格与记忆配置
```

> ⚠️ **改完必须重启 DSH**。这个文件是启动时读一次的，热改不生效。

> 💡 有些配置也能在 DSH 设置面板里改（带 `volatile()` 的字段）。
> 但**以 YAML 为准**，图形界面改的东西有时会被文件覆盖，两边打架很难查。

## 2. ① 通道配置（必须先能连上）

```yaml
- id: im-qqbot-2
  name: '@zaofan/dsh-qqbot'
  config:
    appId: '1900000000'          # ← QQ 开放平台拿的
    appSecret: 'xxxxxxxxxxxx'    # ← QQ 开放平台拿的（保密！）
    settingsNs: 'im-qqbot-2'     # 设置命名空间，和 id 一致即可
```

### 逐项说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `appId` | ✅ | QQ 开放平台的应用 AppID |
| `appSecret` | ✅ | 应用 AppSecret。**别提交到 git、别贴群里** |
| `settingsNs` | 建议 | 设置隔离命名空间。只有一个机器人时等于 `id` |
| `provider` / `model` | 建议 | 用哪个模型。不填则用 profile 默认 |
| `preset` | 建议 | 用哪个 agent 预设（如 `qqbot`） |
| `cwd` | 建议 | AI 的工作目录 |
| `dataRoot` | ✅ **重要** | qqbot 数据根，扩展包就装在这里 |

### 关键的三项

```yaml
        preset: 'qqbot'                                       # agent 预设
        cwd: '{WORKSPACE}/Bot'                                # 工作目录
        dataRoot: '{WORKSPACE}/Bot/dshqqbot'                  # 数据根 ← 扩展包在这
```

> 📌 **`dataRoot` 是整套系统里最重要的一个路径**。
> 扩展包、卡片、记忆库、诊断日志全在它下面。
> 定下来之后**别再改**，改了等于所有数据「消失」（其实是留在旧路径）。

### 会话生命周期（不配会踩坑）

```yaml
        sessionIdleTimeout: 14400000    # 4 小时（默认 30 分钟）
```

> ⚠️ **这个值最好改大**。
> 插件默认 30 分钟没动静就回收会话。而「主动找人说话」这类功能间隔是几小时，
> 等到要说话时会话早就没了 ⇒ 唤醒失败 ⇒ **功能看起来「触发了但没反应」**。
>
> 建议 `14400000`（4 小时）。

### 回复节奏（不配会很慢）

```yaml
        requireMention: false       # true = 必须 @ 她才理
        historyLimit: 50            # 带多少条历史进上下文

        behavior:
          freeIntervalSec: 5        # 没 @ 时的冷却（默认 60 秒！）
          mentionIntervalSec: 0     # @ 时的冷却（0 = 立刻）
          directIntervalSec: 0      # 私聊冷却
          debounce:
            enabled: true
            silenceSec: 1           # 静默多久算「说完了」（默认 3 秒）
            maxMsgs: 10             # 攒够几条立刻开口
            mentionDelayed: false   # @ 的消息不延迟
```

> ⚠️ **`freeIntervalSec` 默认是 60 秒**。很多人反馈「她半天不回」就是这个原因 ——
> 消息收到了，但卡在 60 秒冷却里。改成 5 秒立刻不一样。

### 完整的最小通道配置

```yaml
- insert:
    - id: im-qqbot-2
      name: '@zaofan/dsh-qqbot'
      config:
        appId: '你的appId'
        appSecret: '你的appSecret'
        settingsNs: 'im-qqbot-2'
        preset: 'qqbot'
        cwd: '{WORKSPACE}/Bot'
        dataRoot: '{WORKSPACE}/Bot/dshqqbot'
        sessionIdleTimeout: 14400000
        requireMention: false
        historyLimit: 50
        behavior:
          freeIntervalSec: 5
          mentionIntervalSec: 0
          directIntervalSec: 0
          debounce:
            enabled: true
            silenceSec: 1
            maxMsgs: 10
            mentionDelayed: false
```

## 3. ② 人格 + 记忆配置（`dsh-bnnbotbox`）

```yaml
    - id: bnnbotbox
      name: 'dsh-bnnbotbox'
      config:
        enabled: true
        qqbotDataRoot: '{WORKSPACE}/Bot/dshqqbot'   # 和通道的 dataRoot 一致
        dataRoot: ''                                 # 留空 = 自动推导
```

### 只配这两行能不能跑？

**能。** 全部字段都有默认值，`enabled: true` + `qqbotDataRoot` 对了就能用。

其余 50 个字段都是「想调再调」。下面按用途分组列出**最常改的**。

### 3.1 人格（她是谁）

人格**不是**在这里配的 —— 人格是**文件**：

```
{WORKSPACE}/Bot/人格/
├── 角色卡/小忆.md              ← 人格卡（她是谁、怎么说话）
├── 规则/                       ← 额外规则（安全、群规）
└── persona-config.json         ← 当前用哪个人格
```

`persona-config.json`：

```json
{
  "version": 2,
  "defaultPersona": "小忆",
  "rulesDir": "规则",
  "personasDir": "角色卡"
}
```

**想换人格**：

1. 把新的人格卡放进 `人格/角色卡/你的角色.md`
2. 把 `persona-config.json` 的 `defaultPersona` 改成 `你的角色`
3. 重启 DSH

> 💡 首次安装会自动铺一份「小忆」（最小默认人格）。
> 它只是占位符，**想让她有真正的性格就得自己写卡**。

### 3.2 记忆（记得住人）

| 字段 | 默认 | 说明 |
|---|---|---|
| `memoryRecallEnabled` | `true` | 聊天时把记忆塞进上下文（被动联想） |
| `memoryRecallBudgetChars` | `280` | 记忆注入的字符预算。调大记得多但费 token |
| `memoryRecallRecentDays` | `3` | 「最近」指几天 |

| 字段 | 默认 | 说明 |
|---|---|---|
| `distillEnabled` | — | 从聊天里**抽取人物画像**（关了就记不住人） |
| `autoCardEnabled` | — | **自动生成人物卡 / 群卡** |
| `autoCardGroupEnabled` | — | 是否也自动建群卡 |
| `autoCardMinMessages` | — | 至少聊多少条才建卡（防误判） |

> ⚠️ `distillEnabled` / `autoCardEnabled` 这两个关掉，「记得住人」就废了。
> 但它们是**会调用模型**的（多花钱），介意费用可以只关 `autoCardEnabled`。

### 3.3 主动说话（别让她刷屏）

这是**最容易翻车**的部分：配大了会被群友投诉刷屏，配小了等于没有。

| 字段 | 默认 | 说明 |
|---|---|---|
| `lifeStreamEnabled` | `true` | 主动开口总开关 |
| `lifeStreamDailyMax` | `3` | **每天最多主动说几次**（硬夹 1–3） |
| `lifeStreamMinGapMin` | `90` | **两次之间至少隔几分钟**（硬夹 30–720） |
| `lifeStreamHoursFrom` | `8` | 几点开始允许说话 |
| `lifeStreamHoursTo` | `24` | 几点之后不再说话 |

| 字段 | 默认 | 说明 |
|---|---|---|
| `memoryCallbackEnabled` | `true` | 主动「惦记」老友/生日 |
| `memoryCallbackDailyMax` | `1` | 每天最多惦记几次 |
| `memoryCallbackMinGapDays` | `7` | 多少天没来算「老友」 |
| `memoryCallbackOwnBirthday` | `false` | 是否也惦记自己的生日 |

> 📌 还有一道**全局闸**：同一个群**两次主动说话至少隔 2 小时、一天最多 8 次**，
> 所有主动功能共用这个额度。这是代码里写死的，配置改不了。
> 所以「配了 dailyMax: 3 但只说了 1 次」是正常的 —— 撞上总闸了。

### 3.4 判官与复盘（只在需要时开）

| 字段 | 默认 | 说明 |
|---|---|---|
| `autoJudgeEnabled` | `true` | 自动给她的回复打分（**会调模型**） |
| `autoJudgeRate` | `1` | 打分比例。`0.2` = 只抽 20% |
| `reviewEnabled` | `true` | 定期复盘自己的错 |
| `reviewHour` | `4` | 几点复盘（凌晨 4 点） |

> 💡 **省钱建议**：`autoJudgeRate: 0.2` + `reviewEnabled: false`。
> 判官和复盘都是「后台烧 token」的功能，看不到效果但账单上能看到。

### 3.5 情绪（R4）

情绪系统读 `persona-configs/elysia.json`（文件名是历史沿用，**不是限定角色**）。

| 现象 | 原因 |
|---|---|
| 日志说「模型 ID 为空 ⇒ 禁用后台心跳与提取」 | `elysia.json` 里 `model_config` 的模型 ID 没填 |
| 她情绪一直不变 | 后台任务被关了，或没配模型 |
| 一堆「字典缺失（已降级）」 | 敏感词/同义词/梗库没放，**不影响主聊天** |

> 情绪相关配不好**不影响聊天**，只是她不「有血有肉」。可以最后再弄。

### 完整的人格记忆配置（保守版）

```yaml
    - id: bnnbotbox
      name: 'dsh-bnnbotbox'
      config:
        enabled: true
        qqbotDataRoot: '{WORKSPACE}/Bot/dshqqbot'
        dataRoot: ''

        # 记忆：开着，但控制预算
        memoryRecallEnabled: true
        memoryRecallBudgetChars: 280
        memoryRecallRecentDays: 3
        distillEnabled: true
        autoCardEnabled: true
        autoCardGroupEnabled: true
        autoCardMinMessages: 20

        # 主动说话：克制
        lifeStreamEnabled: true
        lifeStreamDailyMax: 2
        lifeStreamMinGapMin: 120
        lifeStreamHoursFrom: 9
        lifeStreamHoursTo: 23
        memoryCallbackEnabled: true
        memoryCallbackDailyMax: 1
        memoryCallbackMinGapDays: 7

        # 省钱：判官只抽 20%，不复盘
        autoJudgeEnabled: true
        autoJudgeRate: 0.2
        reviewEnabled: false
```

## 4. ③ 玩法扩展配置（`bnn-custom`）

扩展包的配置**不在 YAML 里**，而在它自己的目录：

```
{DATA_ROOT}/extension-packs/bnn-custom/qqbot-pack.json   ← 清单（版本等，一般不改）
```

大部分玩法**没有配置项**，靠命令开关或数据目录。要准备的是**素材**：

| 玩法 | 需要准备 | 放哪 |
|---|---|---|
| `/点歌` | `.mp3`，文件名 `歌名 - 歌手.mp3` | `{WORKSPACE}/Bot/曲库/` |
| `/来张图`、抽奖配图 | `.jpg` / `.png` | `{WORKSPACE}/Bot/美图库/` |
| 生活痕迹 | `.md` 素材 | `{WORKSPACE}/Bot/事件库/` |
| `/语音` | `silk-wasm` 依赖 | 见 [02 · 安装](02-安装.md) |

> ⚠️ **这些目录不会自动建**（空目录没意义）。缺素材时对应玩法给友好提示，不报错。
> 想知道缺什么：`node scripts/doctor.mjs`

### 检查素材是否就位

```bash
cd {DATA_ROOT}/extension-packs/bnn-custom
node scripts/doctor.mjs
```

## 5. 环境变量（可选，用来重定向路径）

不想用默认路径时，用环境变量覆盖。**测试时必须用**，否则会污染生产数据。

| 变量 | 覆盖什么 |
|---|---|
| `QQBOT_DATA_ROOT` | qqbot 数据根 |
| `BNN_WORKSPACE_ROOT` | 工作区根（`Bot/` 的父目录） |
| `BNN_PERSONA_ROOT` | 人格根 |
| `BNN_SONG_ROOT` | 曲库 |
| `BNN_IMAGE_ROOT` | 美图库 |
| `BNN_EVENT_ROOT` | 事件库 |
| `BNN_POINTS_ROOT` | 积分账本 |

> ⚠️ **做测试必须 `QQBOT_DATA_ROOT` 和 `BNN_WORKSPACE_ROOT` 一起设**。
> 只设前者会「半改道」，插件检测到会拒绝写盘，避免污染真实目录。

## 6. 配置完怎么生效

| 改了什么 | 怎么生效 |
|---|---|
| `cordis.patch.yml`（通道/插件配置） | **重启 DSH** |
| 人格卡、`persona-config.json` | **重启 DSH**（30 秒轮询 + 重启） |
| `事实库/`、`事件库/`、记忆数据 | **即时**（每次读盘） |
| 扩展包的 `inbound/` `outbound/` `tools/` | QQ 里发 `/tools-reload` |
| 扩展包的 `hooks/` `commands/` | **重启 DSH** |

## 8. 自检

```bash
# ① YAML 语法对不对
cd {PROFILE_DIR}
node -e "
  const fs=require('fs');
  const t=fs.readFileSync('cordis.patch.yml','utf8');
  console.log('行数:', t.split('\n').length);
  // 粗查：缩进有没有用 tab（YAML 不许 tab）
  const bad=t.split('\n').map((l,i)=>[i+1,l]).filter(([,l])=>/^\t/.test(l));
  console.log(bad.length ? '❌ 有 tab 缩进: 第 '+bad.map(([n])=>n).join(',')+' 行' : '✅ 没有 tab 缩进');
"

# ② 组合后的配置能不能解析（不启动，只打印）
dsh --profile {PROFILE} --dump-config 2>&1 | head -30

# ③ dataRoot 真的存在
ls -d {WORKSPACE}/Bot/dshqqbot

# ④ 人格就位
ls {WORKSPACE}/Bot/人格/角色卡/
cat {WORKSPACE}/Bot/人格/persona-config.json
```

期望：

| 检查 | 期望 |
|---|---|
| YAML 缩进 | ✅ 没有 tab |
| `--dump-config` | 能打印出配置树，不报错 |
| `dataRoot` | 目录存在 |
| 角色卡 | 至少有一个 `.md` |
| `persona-config.json` | `defaultPersona` 指向存在的卡 |
