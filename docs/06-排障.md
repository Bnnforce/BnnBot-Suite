## 1. 症状速查表

| 症状 | 先查 | 最可能的原因 |
|---|---|---|
| **群里完全没反应** | DSH 起来了吗？通道连上了吗？ | 通道没连 / 插件没加载 |
| **@ 她没反应** | 沙箱配置加群了吗？IP 白名单？ | 平台侧没放行 |
| **她半天才回** | `behavior.freeIntervalSec` | **默认 60 秒冷却**，改 5 秒 |
| **她重复回好几条** | 出站去重 | 去重扩展没加载 |
| **斜杠命令没反应** | 重启了吗？ | `commands/` 必须重启，不支持热重载 |
| **卡片点了报「模块加载失败」** | `sync-botplay --check` | 运行时副本没同步 |
| **卡片能开但按钮没反应** | 回调派发日志 | 回调没注册 |
| **记不住人** | `distillEnabled` | 抽取关了 / 模型没调通 |
| **她乱说话/乱发消息** | 主动说话配置 | `lifeStreamDailyMax` 太大 |
| **她的语气不对** | 人格卡 + `persona-config.json` | 指向了错的人格 |
| **她说话被删了几个字** | 出站清洗 | 清洗规则过激 |
| **「主动消息失败, 无权限」** | — | **平台限制，正常现象**，见 [04 §0](04-QQ机器人平台.md) |
| **`机器人非群成员`** | 群成员列表 | 被踢了，重新拉 |
| **`401` / 签名错误** | IP 白名单 + AppSecret | 白名单没配 / Secret 错 |
| **`ERR_MODULE_NOT_FOUND`** | `pnpm install` 跑了吗 | 依赖没装 |
| **插件装了但没挂载** | 重启了吗 | 没重启 |

## 2. 日志在哪（**最容易找错的地方**）

> ⚠️ **插件日志不进 DSH 的 `engine.log`**。
> 你在 engine.log 里翻插件日志，永远翻不到。

| 日志 | 看什么 |
|---|---|
| DSH 应用内日志 / 启动屏 | 宿主级错误 |
| `{DSH_HOME}/data/dsh-bnnbotbox/*.log` | **插件自身** |
| `{DATA_ROOT}/.qqbot-extensions/botplay/botplay-ext.log` | 卡片加载 / 点击 |
| `{DATA_ROOT}/.qqbot-extensions/data/roam-diag.log` | 主动说话 + 出站清洗记录 |
| `{DATA_ROOT}/.qqbot-extensions/data/wake-lottery/diag.log` | 抽奖 |
| `{DATA_ROOT}/.qqbot-extensions/data/security-guard.log` | 工具安全拦截 |
| `{DATA_ROOT}/.qqbot/ext-deliver.log` | **出站投递（平台拒收看这里）** |
| `{DSH_HOME}/qqbot-dispatch-diag.log` | 卡片回调派发 |
| `{DATA_ROOT}/.qqbot-extensions/data/version-guard.json` | 版本/加载状态 |
| `{DATA_ROOT}/.qqbot-extensions/data/workspace-dirs.json` | 启动时建了哪些目录 |

一条命令全看最后几行：

```bash
for f in \
  {DSH_HOME}/data/dsh-bnnbotbox/*.log \
  {DATA_ROOT}/.qqbot-extensions/botplay/botplay-ext.log \
  {DATA_ROOT}/.qqbot-extensions/data/roam-diag.log \
  {DATA_ROOT}/.qqbot/ext-deliver.log ; do
  [ -f "$f" ] && { echo "═══ $f"; tail -5 "$f"; }
done
```

## 3. 「静默失败」专门排查

BnnBot 最坑的一类问题：**装错了不报错，只是不工作**。

| 层 | 什么情况下会被静默跳过 | 怎么确认 |
|---|---|---|
| `inbound/` 扩展 | 导出形态不对（比如只导出 `run`，它只认 `onInbound`） | 见下 |
| 任意扩展 | 顶层抛错 / 依赖 import 不到 | 手动 `import` 一遍 |
| `botplay/` 卡片 | 依赖树没同步 | `sync-botplay --check` + 真的 import |
| `tools/` | 缺 `name` 或 `run` | 手动 import 看导出 |
| 任务/定时 | 执行器没注册（`run()` 提前 return） | 看任务中心日志 |

### inbound 扩展装载自检

```bash
node --input-type=module -e "
const P = '{PROFILE_DIR}/node_modules/@zaofan/dsh-qqbot/dist/features/ext-inbound.js';
const { loadInboundExtensions } = await import('file://' + P);
const r = await loadInboundExtensions({
  dataRoot: '{DATA_ROOT}',
  logger: { info(){}, warn: (m) => console.log('WARN', m) },
});
console.log('total =', r.total, '| skipped =', r.skipped);
console.log('已装载:', r.extensions.map(e => e.file).join(', '));
"
```

**`skipped` 必须是 0**。大于 0 说明有文件没被认出来 —— 而正常运行时**它不会告诉你**。

## 4. 常见配置错误

| 错误 | 后果 | 正确写法 |
|---|---|---|
| YAML 用 **tab** 缩进 | 解析失败，配置整个不生效 | 只能用空格 |
| `appSecret` 两边有空格 | 签名错误 | 去掉首尾空格 |
| `dataRoot` 用了相对路径 | 找不到目录 | 用绝对路径 |
| `dataRoot` 改了位置 | 所有数据「消失」 | 定下来别改，或把旧目录搬过去 |
| `qqbotDataRoot` 和通道的 `dataRoot` 不一致 | 插件和扩展包读不同的地方 | 两个填一样 |
| 扩展包目录名不是 `bnn-custom` | 扫不到 | 必须叫 `bnn-custom` |
| 改完没重启 | 配置没生效 | 重启 |

### 检查 YAML 有没有 tab

```bash
cd {PROFILE_DIR}
grep -nP "^\t" cordis.patch.yml && echo "❌ 上面这些行有 tab" || echo "✅ 没有 tab"
```

### 检查配置能不能被解析

```bash
dsh --profile {PROFILE} --dump-config 2>&1 | head -20
```

能打印出配置树 = 语法没问题。

## 5. 「她说的话被改了」专项

如果她的话**开头几个字没了 / 链接变成 `//` / 换行被压平**：

```bash
grep "\[清洗\]" {DATA_ROOT}/.qqbot-extensions/data/roam-diag.log | tail -10
```

能看到每一条「改前 → 改后」。据此判断是哪条规则误伤。

出站清洗链的顺序（文件名升序）：

```
05-birthday-at-all → 10-ensure-at-back → 20-zz-dedupe-replies
→ 40-strip-tool-leaks → 45-privacy-guard → 50-mood-driver
→ 50-style-guard → 55-sulk-prefix → 56-roam-clean → 60-split-bubbles
```

> ⚠️ 对**所有文本**生效的清洗要格外小心 —— 它会把正常内容一起洗掉。

## 6. 「她主动说话太多/太少」

有两个**独立**的闸，都可能拦住她：

```
① 功能自己的限频      lifeStreamDailyMax / lifeStreamMinGapMin
② 全局发言预算        同群两次至少隔 2 小时、一天最多 8 次（代码写死）
```

所以「配了每天 3 次但只说了 1 次」是正常的 —— 撞上总闸了。

排查：

```bash
# 看这次为什么没说话
grep -E "daily-cap|全局预算不足|让路|skip" {DATA_ROOT}/.qqbot-extensions/data/roam-diag.log | tail -10
```

## 7. 性能问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 回复很慢（十几秒） | 模型本身慢 / 上下文太大 | 换快模型；`historyLimit` 调小 |
| 群里人多就卡 | 每条消息都跑一遍入站扩展 | 检查有没有扩展在热路径做 IO |
| 内存一直涨 | 历史缓存 | 重启；`maxHistoryDays` 调小 |
| 手机很烫 | 后台任务密集 | 关掉判官/复盘（`autoJudgeRate: 0.2`、`reviewEnabled: false`） |

## 8. Android 专属问题

| 现象 | 解决 |
|---|---|
| 后台被系统杀掉 | 加电池优化白名单（App 内有引导） |
| `/tmp` 不可写 | 用 `os.tmpdir()` 或工作区下的临时目录 |
| `ln -s` 失败 | FUSE 不支持软链，用复制 |
| `tar czf` 失败 | 没 gzip，用 `cp -r` |
| 文件复制报 `Operation not permitted` | FUSE 限制，用 node 的 `copyFileSync` 分文件复制 |
| 引擎启动即崩 | APK 架构装错了（arm64 / x86_64），重装对应包 |
