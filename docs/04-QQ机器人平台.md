# 04 · QQ 机器人平台配置

> **目标**：拿到 `appId` / `appSecret`，让机器人能连上 QQ、能在群里说话。
> **做完的判据**：日志里出现「已连接」，群里 @ 她有反应。

> ⚠️ QQ 开放平台的界面**经常改版**。本篇写的是**流程和要填什么**，
> 具体按钮位置**以平台当前界面为准**。

---

## 0. 先知道一个残酷事实（很重要）

QQ 官方机器人**不是你想怎么发就怎么发**。有两个硬限制：

| 限制 | 说明 |
|---|---|
| **主动消息受限** | 官方自 2025 年起大幅收紧主动消息。**没有「被动回复窗口」时，主动发消息会失败** |
| **被动回复窗口** | 群聊：收到消息后 **5 分钟内最多回 5 条**；单聊：**60 分钟内最多 4 条** |

这意味着：

- ✅ **能正常用**：你 @ 她 → 她在窗口内回复
- ⚠️ **可能失败**：她自己想主动说话（主动逛、主动惦记、睡醒抽奖）
- ❌ **一定失败**：没人说话时她突然发言

如果你在日志里看到：

```
主动消息失败, 无权限
```

**这不是 BnnBot 的 bug**，是平台限制。BnnBot 的处理是「尝试失败就安静放弃」，不会报错刷屏。

> 📌 所以「主动说话」相关配置请**保守设置**，别指望她能随便开口。

## 1. 注册与认证

1. 打开 **QQ 开放平台**：<https://q.qq.com>
2. 用 QQ 号登录（或用邮箱注册）
3. 完成 **主体认证**
   - 个人主体：身份证实名
   - 企业主体：营业执照 + 对公账户

> 个人开发者可以申请，群聊场景个人主体也能用。

---

## 2. 创建机器人

1. 登录后进「机器人」列表
2. 点 **创建机器人**
3. 填基本信息：**名称、简介、头像**

> 💡 机器人名称会显示在群里，建议取个像人名的（比如「小忆」），
> 不要叫「XX机器人助手」—— 群友对她的态度会不一样。

---

## 3. 拿 AppID / AppSecret（关键）

进机器人的 **开发管理 / 开发设置** 页面：

| 字段 | 长什么样 | 注意 |
|---|---|---|
| **AppID** | 一串数字，如 `1900000000` | 复制保存 |
| **AppSecret** | 一串字母数字 | ⚠️ **只显示一次**，丢了要重置 |

> 🔒 **AppSecret 等于机器人密码**：
> - 别提交进 git
> - 别贴群里
> - 别发截图
> 拿到就填进 `cordis.patch.yml`，然后关掉那个页面。

---

## 4. IP 白名单（如果机器人要发消息）

BnnBot 的连接方式：

```
收消息：WebSocket 长连接（不需要公网 IP、不需要域名）
发消息：调用 OpenAPI（需要把「出口 IP」加白名单）
```

所以**要发消息就得配 IP 白名单**：

1. 先查这台机器的公网出口 IP：

```bash
curl -s https://ifconfig.me
```

2. 在平台 **开发管理 → IP 白名单** 里把 IP 加进去

> ⚠️ 家庭宽带 / 手机网络的 IP 会变。IP 一变，发消息就失败（收消息还能用）。
> 这也是推荐**用固定 IP 的服务器**跑的原因之一。
>
> 💡 如果日志里出现 `API Error ... 401` / `签名` 类错误，先回来检查 IP 白名单。

## 5. 沙箱配置（新机器人必须做）

**新创建的机器人默认在沙箱里**，只有你添加的测试群/测试用户能跟它说话。

### 加测试群

1. 平台里进 **沙箱配置**
2. 添加你的测试 QQ 群
3. 按提示把机器人**拉进那个群**

### 沙箱的几个常见坑

| 现象 | 原因 |
|---|---|
| 拉进群了但它一句话不说 | 群没加进沙箱配置 |
| 单聊没反应 | 你的 QQ 号没加进沙箱用户 |
| 「机器人非群成员」 | 机器人被移出群了，重新拉 |

---

## 6. 群里的权限

| 项 | 说明 |
|---|---|
| **@ 她** | 分群默认只响应 @。想让它在群里收到所有消息，得看平台「群聊配置」里是否允许全量接收 |
| **群主/管理员操作** | 机器人只能被群主或管理员拉进群 |
| **是否需要审核** | 沙箱内可以直接用；给**非沙箱的群**用需要提交审核上线 |

> 💡 BnnBot 的配置里有个 `requireMention: false`，
> 意思是「**技术上**不强制 @」。但 QQ 平台层面**可能**还是只推 @ 消息给你，
> 这取决于该群的配置。看不到非 @ 消息时，先查平台侧，不是 BnnBot 的问题。

---

## 7. 上线（想给别人的群用）

沙箱只能自己测试。要给正式群用：

1. 平台上提交 **上线审核**
2. 审核内容通常包括：功能说明、使用场景、隐私说明
3. 通过后机器人才能被任意群添加

> 📌 上线审核需要你对**隐私处理**有明确说法。
> 如果打算给别人用，建议先读
> [dsh-bnnbotbox/PRIVACY.md](https://github.com/Bnnforce/dsh-bnnbotbox/blob/main/PRIVACY.md)，
> 那里面写清了数据怎么处理，可以直接改写用于审核材料。

## 8. 事件订阅（Intents）

QQ 机器人用一组位掩码声明「我要收哪些事件」。BnnBot 需要的核心两个：

| Intent | 值 | 用途 |
|---|---|---|
| 群聊和 C2C 消息 | `1 << 25` | 群消息（@ 她）、单聊消息 |
| @ 消息（公域） | `1 << 30` | 部分场景的 @ 消息 |

> 如果频道（GUILD）也要用，再加 `1 << 0`（频道）、`1 << 1`（成员）、`1 << 12`（私信）。

**这个不用你填** —— `@zaofan/dsh-qqbot` 自己会订阅。这里知道原理就行，
排查「收不到消息」时可以对照。

## 9. 验收：机器人真的连上了吗

### ① 看 DSH 日志

```bash
# 命令行启动的直接看屏
# App 里跑的看应用内日志面板
```

期望看到连接成功、心跳之类的记录。

### ② 在群里 @ 她

```
@你的机器人 你好
```

期望：她用自己的人设语气回你。

### ③ 查诊断文件

```bash
cat {DATA_ROOT}/.qqbot-extensions/data/version-guard.json
```

期望 `"status": "ok"`。

### ④ 看消息有没有真的收发

```bash
# 出站投递结果（平台拒收会写这里）
cat {DATA_ROOT}/.qqbot/ext-deliver.log 2>/dev/null | tail -5
```

- 空文件或没有报错 = 正常
- `主动消息失败, 无权限` = 平台限制（见 §0，正常现象）
- `机器人非群成员` = 被踢了，重新拉
- `401` / 签名错误 = AppSecret 错或 IP 白名单没配

## 10. 常见问题

| 问题 | 答案 |
|---|---|
| 个人能申请吗 | 能。群聊场景个人主体可用 |
| 要公网服务器吗 | **不用**。WebSocket 长连接，手机/NAS 都行 |
| 要域名和 SSL 吗 | **不用**（那是 Webhook 模式才需要） |
| 一个机器人能进几个群 | 看平台策略；沙箱内限测试群，上线后按平台限制 |
| AppSecret 泄露了 | 赶紧在平台**重置**，然后改配置重启 |
| 能自己发消息给用户吗 | 受限。见 §0 |
| 平台界面找不到某菜单 | 界面常改版，按「开发管理 / 沙箱配置 / IP 白名单」这几个关键词找 |
