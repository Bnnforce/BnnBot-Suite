# 02 · 安装

> **目标**：把三个包装进 DSH，并且确认它们真的被加载了。
> **做完的判据**：本篇 §6 的验证全部通过。

---

## 安装顺序（不能乱）

```
① @zaofan/dsh-qqbot      ← 先装通道（没有它，后面两个没地方挂）
      ↓
② dsh-bnnbotbox          ← 再装人格 + 记忆插件
      ↓
③ dsh-qqbot-bnn-custom   ← 最后放扩展包（它依赖通道的扩展点）
```

> 顺序错了会怎样：先装 ③ 的话，扩展包会被当成「找不到宿主的孤儿」跳过，
> 而且**不会报错**，你会以为装好了。

---

## ① 装通道插件 `@zaofan/dsh-qqbot`

这是第三方插件（不是本套组的），但它是 QQ 通道，必须有。

### 命令行

```bash
dsh plugin --profile {PROFILE} add @zaofan/dsh-qqbot
```

或者直接进 profile 目录用 pnpm：

```bash
cd {PROFILE_DIR}
pnpm add @zaofan/dsh-qqbot
```

### 验证

```bash
ls {PROFILE_DIR}/node_modules/@zaofan/dsh-qqbot/package.json
node -e "console.log(require('{PROFILE_DIR}/node_modules/@zaofan/dsh-qqbot/package.json').version)"
```

期望：打印出版本号（≥ `1.13.16`）。

---

## ② 装人格 + 记忆插件 `dsh-bnnbotbox`

### 先拿到代码

```bash
cd ~
git clone https://github.com/Bnnforce/dsh-bnnbotbox.git
cd dsh-bnnbotbox
```

### 装它的依赖

```bash
pnpm install
```

> ⚠️ 这一步不能省。仓库**不含** `node_modules`，
> 少了 `@deepseek-ai/schemastery` 之类的依赖，插件一加载就 `ERR_MODULE_NOT_FOUND`。

### 挂进 profile

**方式 A：命令行（推荐）**

```bash
dsh plugin --profile {PROFILE} add link:$HOME/dsh-bnnbotbox
```

等价于在 `{PROFILE_DIR}` 里执行：

```bash
pnpm add "link:$HOME/dsh-bnnbotbox"
```

**方式 B：图形界面**

DSH 的 **Plugins（插件）→ Add plugin（添加插件）**，选 `dsh-bnnbotbox` 所在目录。

**方式 C：让 AI 装（适合把这个仓库丢给 DSH 的场景）**

让 DSH 调用 `plugin_manager`：

```
action: install_bundle
target: /绝对路径/dsh-bnnbotbox
```

### 验证

```bash
# ① profile 依赖里有了
node -e "console.log(require('{PROFILE_DIR}/package.json').dependencies['dsh-bnnbotbox'])"
# 期望输出：link:...

# ② 能自己加载（不需要 DSH，直接 import 试试）
cd {PROFILE_DIR}
node --input-type=module -e "
  const m = await import('dsh-bnnbotbox');
  console.log('组件名:', m.name);
  console.log('配置字段数:', Object.keys(m.Config.dict).length);
  console.log('依赖:', m.inject);
"
```

期望输出：

```
组件名: bnnbotbox
配置字段数: 52
依赖: [ 'systemPrompt', 'llm', 'tools' ]
```

> **字段数必须是 52**。如果显示 32，说明装的是老版本（配置没合并，memory 那 20 个字段看不到）。

## ③ 放扩展包 `dsh-qqbot-bnn-custom`

扩展包**不是** pnpm 包，是直接复制进 `dataRoot` 的目录。

### 先拿到代码

```bash
cd ~
git clone https://github.com/Bnnforce/dsh-qqbot-bnn-custom.git
```

### 复制到 dataRoot

```bash
mkdir -p {DATA_ROOT}/extension-packs
cp -r ~/dsh-qqbot-bnn-custom {DATA_ROOT}/extension-packs/bnn-custom
```

> ⚠️ **目录名必须是 `bnn-custom`**（不是 `dsh-qqbot-bnn-custom`）。
> 数据路径和停用清单都按这个名字找，改了会找不到。

> 📌 `{DATA_ROOT}` 是 qqbot 的 `dataRoot`，通常是 `{WORKSPACE}/Bot/dshqqbot`。
> 如果你还没配过，先看 [03 · 配置](03-配置.md)，配完再回来。

### 装它的可选依赖（想让它发语音条才需要）

```bash
cd {DATA_ROOT}/extension-packs/bnn-custom
pnpm add silk-wasm
```

> 不装也能跑，只是 `/语音` 和点歌的「发语音条」会退化成文字提示。

### 验证

```bash
cd {DATA_ROOT}/extension-packs/bnn-custom

# ① 语法自检（应该 205 个 .mjs 全过）
node scripts/check-syntax.mjs

# ② 环境自检（看路径对不对、缺什么）
node scripts/doctor.mjs

# ③ 卡片运行时副本是否就绪
node scripts/sync-botplay.mjs --check
```

期望：`check-syntax` 打 `✅ 语法全部通过`；`doctor` 打 `✅ 必需目录齐全`；
`sync-botplay --check` 打 `✓ 全部已同步`。

如果 `doctor` 报「必需目录缺」：

```bash
node scripts/doctor.mjs --fix
```

## 4. 重启 DSH

**必须重启**，不是热重载。

```bash
# 命令行启动的
# Ctrl+C 停掉，再 dsh --profile {PROFILE}

# App 里跑的
# 设置 → 重启引擎（或杀掉 App 重开）
```

> 为什么必须重启：`hooks/`（启动钩子）和 `commands/`（斜杠命令）**不支持热重载**。
> 只有 `inbound/` `outbound/` `tools/` 三层能靠 QQ 里发 `/tools-reload` 刷新。

---

## 5. 首次启动会自动做什么

别惊讶，第一次起来会自己建东西（**只在缺失时建，不覆盖已有的**）：

| 动作 | 结果 |
|---|---|
| 铺最小默认人格 | `{WORKSPACE}/Bot/人格/角色卡/小忆.md` + `persona-config.json` |
| 建必需数据目录 | `Bot/人格/`、`Bot/人格/积分/`、`.qqbot-extensions/data/` |
| 同步卡片 | 13 张卡片搬到 `.qqbot-extensions/botplay/`，`lib/` 依赖树一起搬 |

看它做了什么：

```bash
cat {DATA_ROOT}/.qqbot-extensions/data/workspace-dirs.json
```

## 6. 全部装完的验证

按顺序跑，全过才算装好。

```bash
# ── 组件层 ──────────────────────────────────────────
cd {PROFILE_DIR}
node -e "console.log('qqbot:', require('./node_modules/@zaofan/dsh-qqbot/package.json').version)"
node -e "console.log('bnnbotbox:', require('./package.json').dependencies['dsh-bnnbotbox'])"

# ── 插件层 ──────────────────────────────────────────
node --input-type=module -e "
  const m = await import('dsh-bnnbotbox');
  console.log('name:', m.name, '| 配置字段:', Object.keys(m.Config.dict).length, '| inject:', m.inject.join(','));
"

# ── 扩展包层 ────────────────────────────────────────
cd {DATA_ROOT}/extension-packs/bnn-custom
node scripts/check-syntax.mjs | tail -2
node scripts/doctor.mjs | tail -4

# ── 运行时层（重启后才有数据）──────────────────────
cat {DATA_ROOT}/.qqbot-extensions/data/version-guard.json
cat {DATA_ROOT}/.qqbot-extensions/data/workspace-dirs.json
```

**通过标准**：

| 检查 | 期望 |
|---|---|
| qqbot 版本 | ≥ 1.13.16 |
| bnnbotbox 依赖 | `link:...` 存在 |
| 插件 name | `bnnbotbox` |
| **配置字段数** | **52** |
| 扩展包语法 | `✅ 语法全部通过` |
| doctor | `✅ 必需目录齐全` |
| `version-guard.json` | `"status": "ok"`，`pack` 有值 |

## 7. 装不上时

先看 [06 · 排障](06-排障.md)。这里列三个最高频的：

| 现象 | 原因 | 解决 |
|---|---|---|
| `dsh: command not found` | DSH 没装或不在 PATH | 回 [01 · 环境准备](01-环境准备.md) |
| 插件装了但 DSH 没反应 | 没重启 | 重启，不是热重载 |
| `ERR_MODULE_NOT_FOUND: @deepseek-ai/schemastery` | 没跑 `pnpm install` | 进插件目录跑一次 |
| 扩展包加载不出来 | 目录名不是 `bnn-custom` | 改名 |
| 卡片点了报「模块加载失败」 | 没同步运行时副本 | `node scripts/sync-botplay.mjs` |
