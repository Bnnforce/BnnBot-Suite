# 05 · 测试与验收

> **目标**：确认每一块**真的在工作**，而不是「看起来装好了」。
> **原则**：**文件存在 ≠ 能跑。** 判据必须是「真的能加载 / 真的回了话」。

---

## 为什么要分层测

BnnBot 跨了四层，任何一层断了表现都是「群里没反应」：

```
① 宿主层       DSH 起来了没
② 插件层       dsh-bnnbotbox 加载了没
③ 扩展包层     bnn-custom 被扫到了没
④ 运行时层     卡片/命令/记忆真的能用吗
```

**从下往上测**，哪层报错就停在那层修，别跳。

---

## 第 ① 层：宿主

```bash
dsh --version
# 期望：版本号 >= 0.2.0-rc.2

ls -d "$DSH_HOME" || ls -d ~/.dsh
# 期望：目录存在
```

---

## 第 ② 层：插件能加载

这一层**不用启动 DSH**，直接 import 就能测：

```bash
cd {PROFILE_DIR}

node --input-type=module -e "
  const m = await import('dsh-bnnbotbox');
  console.log('组件名 :', m.name);
  console.log('配置字段:', Object.keys(m.Config.dict).length);
  console.log('依赖   :', m.inject.join(', '));
"
```

**通过标准**：

| 输出 | 期望 | 不对说明什么 |
|---|---|---|
| `组件名` | `bnnbotbox` | 装错包 / 路径不对 |
| `配置字段` | **`52`** | `32` = 老版本（配置没合并） |
| `依赖` | `systemPrompt, llm, tools` | 版本不对 |

### 加载失败时

```bash
# 常见：忘了 pnpm install
cd ~/dsh-bnnbotbox && pnpm install && cd {PROFILE_DIR}

# 还是失败就看具体缺什么
node --input-type=module -e "await import('dsh-bnnbotbox')" 2>&1 | grep "Cannot find"
```

## 第 ③ 层：扩展包被扫到

```bash
cd {DATA_ROOT}/extension-packs/bnn-custom

# ① 语法（205 个 .mjs）
node scripts/check-syntax.mjs

# ② 路径与目录
node scripts/doctor.mjs

# ③ 卡片运行时副本
node scripts/sync-botplay.mjs --check
```

**通过标准**：

| 命令 | 期望输出 |
|---|---|
| `check-syntax` | `检查 205 个 .mjs` + `✅ 语法全部通过` |
| `doctor` | `✅ 必需目录齐全` |
| `sync-botplay --check` | `✓ 全部已同步（卡片 13 个 / lib ... 个）` |

### 关键：卡片真的能加载吗

`sync-botplay --check` 显示「已同步」还不够 —— 要**真的 import 一遍**：

```bash
cd {DATA_ROOT}/.qqbot-extensions/botplay
node --input-type=module -e "
import fs from 'node:fs';
let ok = 0; const bad = [];
for (const f of fs.readdirSync('.').filter(x => x.endsWith('.mjs'))) {
  try { await import('file://' + process.cwd() + '/' + f + '?v=' + Date.now()); ok++; }
  catch (e) { bad.push(f + ': ' + e.message.slice(0, 60)); }
}
console.log('卡片 ' + ok + '/13', bad.length ? '❌' : '✅');
bad.forEach(b => console.log('  ', b));
"
```

**期望 `卡片 13/13 ✅`**。

> ⚠️ 这一步**必须做**。历史事故：13 张卡文件都在、检查器全绿，
> 实际一张都加载不了（`lib/` 依赖树没同步过去）。

## 第 ④ 层：运行时（真机测）

**重启 DSH**，然后按顺序做这 6 项。每项做不了就跳过，记录一下。

### ① 群里 @ 她

```
@你的机器人 你好
```

| 期望 | 失败说明 |
|---|---|
| 有回复，用她自己的语气 | 没回复 → 查通道配置 |
| 回复里带 @ 你的标记 | 不带 → 出站链问题 |
| 8 秒内不重复 | 重复 → 去重失效 |

### ② 让她调工具

```
@你的机器人 现在几点
```

| 期望 | 失败说明 |
|---|---|
| 用自己语气说出时间 | 说「我无法获取当前时间」→ 工具没注册 |

### ③ 斜杠命令

群里发：

```
/签到
```

| 期望 | 失败说明 |
|---|---|
| 有响应（签到成功/已签到） | 无响应 → 命令扩展没加载（需要重启，不是热重载） |

### ④ 卡片按钮

发 `/玩法`，点卡片里的按钮。

| 期望 | 失败说明 |
|---|---|
| 卡片能打开、按钮能点 | 报「模块加载失败」→ 回第 ③ 层同步卡片 |

### ⑤ 记忆（她记不记得）

```
@你的机器人 我叫小明
```
等一会儿再：
```
@你的机器人 我叫什么
```

| 期望 | 失败说明 |
|---|---|
| 能说出「小明」 | 记不住 → `distillEnabled` 关了，或模型没调通 |

> 💡 记忆是**异步抽取**的（不是当场记），可能要等几分钟或下一轮才生效。

### ⑥ 主动说话

这个**不用专门测**，观察就行：

```bash
cat {DATA_ROOT}/.qqbot-extensions/data/roam-diag.log 2>/dev/null | tail -10
```

看到 `[主动逛]` / `[触发]` 这类记录说明调度在跑。
但**真的发出去了没有**要看 `ext-deliver.log`（平台可能拒收，见 [04 篇 §0](04-QQ机器人平台.md)）。

## 汇总自检脚本

把前 3 层一次跑完：

```bash
echo '=== ① 宿主'
dsh --version

echo '=== ② 插件'
cd {PROFILE_DIR}
node --input-type=module -e "
  const m = await import('dsh-bnnbotbox');
  const n = Object.keys(m.Config.dict).length;
  console.log(n === 52 ? '✅ 配置 52 字段' : '❌ 配置只有 ' + n + ' 字段');
"

echo '=== ③ 扩展包'
cd {DATA_ROOT}/extension-packs/bnn-custom
node scripts/check-syntax.mjs | tail -1
node scripts/doctor.mjs | tail -3
node scripts/sync-botplay.mjs --check | tail -1

echo '=== 运行时状态'
cat {DATA_ROOT}/.qqbot-extensions/data/version-guard.json 2>/dev/null
```

## 验收清单

逐项打勾，全勾完就算装好了。

- [ ] `@zaofan/dsh-qqbot` 版本 `>= 1.13.16`

- [ ] 扩展包语法自检通过
- [ ] `doctor` 报必需目录齐全
- [ ] 卡片 `13/13` 可加载

- [ ] `appId` / `appSecret` 已填
- [ ] `dataRoot` 指向正确位置
- [ ] `sessionIdleTimeout` 改成 4 小时
- [ ] `freeIntervalSec` 改成 5 秒
- [ ] 人格卡存在，`persona-config.json` 指向它
- [ ] 重启过 DSH

### 真机
- [ ] @ 她有回复

- [ ] 斜杠命令有响应
- [ ] 卡片能打开、按钮能点
- [ ] 她记得住人（异步，可稍后再测）

- [ ] 知道日志在哪（见 [06 · 排障](06-排障.md)）
